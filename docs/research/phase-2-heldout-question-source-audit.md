# Phase 2 held-out question source audit

## Active v9 source review — assistant-reviewed 2026-09-28

The fresh held-out set contains ten source-reviewed families drawn from the accepted
100-paper snapshot. Positive source anchors and snapshot-scoped unsupported screens
were reviewed before final candidate judgments and scoring. Held-out question and
source identities remain private.

Positive anchors were checked against accepted source extractions and primary
publisher sources. Publisher PDF evidence was cross-checked where applicable. For
one table source, the publisher PDF page index differed by one from the accepted
extraction; the table caption and target row were cross-checked, and accepted-
extraction coordinates remain authoritative. Each positive anchor was mapped using the frozen prose-span or exact-table-
row rules. Nine direct anchors have nine direct candidate links in the pooled review
cards. The three unsupported checks were screened against all pooled paper and
evidence candidates; they remain bounded to the fixed snapshot and do not make
claims about the wider literature.

All 339 paper candidates and 496 evidence candidates have assistant-reviewed 0/1/2
labels. Candidate cards were shuffled and omitted profile, rank and score origins.
The source map binds to the final reviewed cards and frozen split. The raw questions,
paper identities, passages, source locations and retrieval results remain in the
ignored private run directory.

Earlier held-out sets are spent and excluded from further selection. The v9 set is
also spent: its aggregate result missed the paper nDCG@10 gate. Use development data
for any repair and a newly frozen source-reviewed set for any later acceptance
assessment. This audit contains source-review coverage only; aggregate retrieval
outcomes are in the [acceptance report](../reference/phase-2-acceptance-report.md).
